Data Lake & Analytics de Cinema

Estágio — AI/R Compass UOL

Obs: Este megaprojeto foi construído em múltiplas etapas, cobrindo o ciclo de vida completo do dado: Ingestão (Raw), Processamento (Trusted), Modelagem (Refined) e Consumo (Dataviz).

  • Ingestão (Raw): Desenvolvimento de pipeline automatizado integrando dados de CSVs e da API do TMDB via Python e AWS Lambda, salvos de forma estruturada na AWS S3.
  • Processamento (Trusted): Tratamento de valores ausentes e tipagem de dados. "Achatamento" (flatten) de estruturas JSON aninhadas utilizando a função explode via PySpark no AWS Glue.
  • Modelagem Dimensional (Refined): Estruturação de dados com Fact Constellation Schema, envolvendo tabelas factless (fato_participacao) e resolução de relações N:N com tabelas ponte.
  • Modelagem Analítica no Athena: Criação de uma View avançada (vw_filmes_analise) no AWS Athena, unificando 5 dimensões e 2 tabelas fato para centralizar métricas complexas e fornecer uma "fonte única da verdade".
  • DataViz & Storytelling: Construção de dashboards imersivos no Amazon QuickSight consumindo a View do Athena, adotando storytelling visual com paleta de cores inspirada em ícones do terror (Freddy Krueger).
